# 基于 SpringBoot + Vue  的学校教学教务系统

学生管理 · 课程管理 · 班级课表 · 选课预约 · 成绩管理 · 导师管理 · 资源共享 · 消息通知 · 数据统计

本项目是一套面向高校/职业院校/培训机构的现代化教学教务管理平台，采用前后端分离架构，覆盖**管理员、教师、学生**三类核心角色。系统围绕"学生管理、教师管理、课程管理、班级课表、选课预约、成绩管理、导师管理、选修课管理、资源共享、消息通知、数据统计"等核心业务设计，支持从学生入学、课程开设、排课选课、成绩录入，到资源共享、师生沟通、数据统计的全链路数字化运营，构建"人—课—班—绩"一体化的教学教务管理平台。

## 核心特性

- **院系专业班级层级管理**：支持"系→专业→班级"三级组织架构管理，管理员可维护系部信息、专业设置、班级划分，支持班级学生批量导入与学籍管理。
- **课程与排课管理**：管理员可创建课程（课程代码、名称、学分、学时、课程性质必修/选修、开课学期），配置授课教师与上课时间地点，支持班级课表与选修课表自动生成，提供课表模板功能便于快速排课。
- **选课预约与审核**：学生可在线浏览可选课程、提交选课预约申请，教师端进行选课审核（通过/拒绝），支持选课容量控制、时间冲突检测、退课释放名额，确保选课数据一致性。
- **成绩管理**：教师可按课程录入学生成绩（平时成绩、期末成绩、总评成绩），支持批量导入与成绩修改留痕；学生可查看个人课程分数与选修分数；管理员可统计各班级/课程成绩分布。
- **导师管理**：管理员可配置导师信息、分配指导学生，学生可查看自己的导师信息，支持导师与学生之间的学业指导与沟通。
- **共享文件与教学资源**：支持教师上传课程资料、课件、教学文档，学生可浏览下载，管理员可管理文件库，实现教学资源共享。
- **留言与消息通知**：学生可向管理员/教师发布留言反馈问题，管理员与教师可回复；系统支持消息通知推送（选课结果、成绩发布、公告提醒等），确保信息及时传达。

## 功能模块概览

## 管理员端

管理员为平台最高权限角色，负责全局配置与数据监管：

### 账号与组织架构

- **管理员管理**：管理管理员账号，包括账号增删改查、角色分配、权限配置、登录日志查看，支持修改密码与安全设置。
- **学生管理**：管理学生档案，包括学号、姓名、性别、所属系/专业/班级、入学年份、学籍状态、联系方式，支持学生信息增删改查、批量导入、学籍异动（休学/复学/退学）处理、账户冻结/解冻。
- **导师管理**：管理导师信息，包括工号、姓名、所属系/专业、职称、研究方向、指导学生列表，支持导师信息增删改查与指导学生分配。
- **系管理**：管理学校系部信息，包括系名称、系代码、系主任、系描述，支持系部增删改查。
- **专业管理**：管理专业设置，包括专业名称、专业代码、所属系、学制、专业描述，支持专业增删改查。
- **班级管理**：管理行政班级，包括班级名称、所属专业、班主任、入学年份、班级人数，支持班级增删改查与学生分配。
- **部门管理**：管理学校职能部门信息，包括部门名称、部门负责人、部门职能描述，支持部门增删改查。
- **岗位管理**：管理教师岗位/职务字典，包括岗位名称（教授/副教授/讲师/助教等）、岗位描述、岗位权限，支持岗位增删改查。

### 课程与排课

- **课程信息**：管理全校课程库，包括课程代码、课程名称、学分、学时、课程性质（必修/选修/通识）、开课学期、先修课程、课程描述，支持课程增删改查。
- **班级课表**：查看与管理各班级课表，包括课程、授课教师、上课时间（星期/节次）、上课地点（教室），支持课表编辑、调课、临时停课处理。
- **选修课表**：管理选修课程表，包括选修课程列表、授课教师、上课时间地点、选课容量、已选人数，支持选修课开设与关闭。
- **课表模板**：管理排课模板，预设常用排课规则与时间模板（如一周5天×每天8节），支持快速应用模板生成课表，提高排课效率。

### 选课与成绩

- **选课预约**：查看学生选课预约申请记录，包括申请人、申请课程、申请时间、审核状态，支持批量审核与选课结果导出。
- **课程分数**：查看全校课程成绩数据，支持按班级/课程/学期筛选，查看成绩分布统计、及格率、平均分等，支持成绩报表导出。
- **选修课分数**：查看选修课成绩记录，包括学生、选修课程、成绩、学分获得情况，支持选修课成绩统计分析。

### 资源与沟通

- **公告管理**：发布与管理平台公告，包括公告标题、内容、类型（通知/调课/考试安排/放假通知）、发布时间、置顶状态、可见范围（全体/指定系/指定班级），支持公告编辑与删除。
- **共享文件**：管理共享文件库，包括文件名称、分类（课程资料/教学文档/通知公告/其他）、上传者、上传时间、下载次数、可见范围，支持文件审核、分类管理、违规文件处理。
- **留言信息**：查看学生/教师提交的留言，包括留言内容、留言人、留言时间、处理状态，支持管理员回复与留言删除。
- **消息通知**：管理系统消息推送，包括消息标题、内容、接收对象（全体/指定角色/指定班级/指定个人）、发送状态，支持批量发送系统通知（如选课开始通知、成绩发布通知）。

### 数据

- **数据统计**：综合数据看板，展示核心运营指标（学生总数/教师总数/课程总数/今日选课数/本月成绩录入数），支持学生增长趋势、选课热度排行、成绩分布分析、班级课表统计、教师授课量统计等多维度图表展示，支持报表导出。

## 教师端

教师为教学执行方，负责课程教学、成绩录入与学生管理：

### 账号与个人

- **注册登录**：支持工号+密码登录，首次登录由管理员分配账号，支持找回密码。
- **密码修改**：支持教师自主修改登录密码，保障账户安全。
- **我的信息**：查看与编辑个人基本信息，包括工号、姓名、所属系/专业、职称、联系方式、研究方向，支持头像上传。

### 课程与课表

- **我的课程**：查看本学期所授课程列表，包括课程名称、授课班级、上课时间地点、课程性质、选课人数，支持课程详情查看。
- **班级课表**：查看所授班级的课表，包括课程安排、上课时间地点，支持课表导出与打印。
- **选修课表**：查看所授选修课的课表与选课学生名单，支持选修课学生管理。
- **班级学生**：查看所授课程对应的班级学生名单，包括学号、姓名、班级、联系方式，支持学生信息查询。

### 选课与成绩

- **选课审核**：查看学生提交的选课预约申请，包括申请人信息、申请课程、申请时间，支持审核通过或拒绝，审核结果实时通知学生。
- **选课分数**：查看所授课程的选课学生成绩录入情况，包括已录入/未录入学生统计。
- **课程分数**：按课程录入学生成绩，支持平时成绩、期末成绩、总评成绩分项录入，支持批量导入（Excel）、成绩修改（留痕）、成绩提交与发布，发布后学生端可见。

### 资源与沟通

- **共享文件**：上传与管理课程相关资料，包括课件、教学文档、作业要求、参考材料，支持文件分类、版本管理，学生端可见可下载。
- **留言信息**：查看学生提交的留言，包括留言内容、留言人、留言时间，支持回复学生留言，形成师生沟通闭环。
- **我的消息**：查看个人收到的所有系统消息，包括选课审核提醒、公告通知、留言回复、成绩发布提醒等，支持已读/未读管理。

## 学生端

学生为学习主体，负责选课学习、成绩查询与资源共享：

### 账号与个人

- **注册登录**：支持学号+密码登录，首次登录由管理员分配账号，支持找回密码。
- **密码修改**：支持学生自主修改登录密码，保障账户安全。
- **个人信息**：查看与编辑个人基本信息，包括学号、姓名、性别、所属系/专业/班级、入学年份、联系方式、紧急联系人，支持头像上传。

### 课表与选课

- **班级课表**：查看本班级的课程表，包括课程名称、授课教师、上课时间（星期/节次）、上课地点（教室），支持课表导出与打印。
- **选修课表**：查看可选选修课列表，包括课程名称、授课教师、上课时间地点、课程容量、已选人数、课程描述，支持选课详情查看。
- **我的预约**：查看本人提交的选课预约记录，包括申请课程、申请时间、审核状态（待审核/已通过/已拒绝），支持预约取消（审核前）。

### 成绩

- **课程分数**：查看本人必修课成绩，包括课程名称、授课教师、平时成绩、期末成绩、总评成绩、学分、获得学期，支持按学期筛选与成绩导出。
- **选修分数**：查看本人选修课成绩，包括选修课程名称、授课教师、成绩、学分获得情况，支持选修课成绩统计。

### 资源与沟通

- **共享文件**：浏览与下载共享文件库中的资料，支持按分类搜索（课程资料/教学文档/通知公告），查看文件详情与下载。
- **我的留言**：向管理员或教师发布留言，包括留言内容、留言类型（问题反馈/建议意见/请假申请），支持查看留言回复记录。
- **我的消息**：查看个人收到的所有系统消息，包括选课结果通知、成绩发布通知、公告提醒、留言回复等，支持已读/未读管理。
